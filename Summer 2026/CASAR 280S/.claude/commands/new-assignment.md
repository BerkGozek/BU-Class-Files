---
description: Scaffold a new assignment folder following this course's Assignments/ pattern
argument-hint: [assignment name, e.g. "Food Journal Assignment 3"]
---

Set up a new assignment folder for: $ARGUMENTS

1. Check `Assignments/` for the most recent existing assignment folder to confirm the naming convention and which casing (`Work Done` vs `work done`) it used for the submission subfolder.
2. Create `Assignments/$ARGUMENTS/` with a `Work Done/` subfolder, matching that casing convention.
3. If the user has a new assignment docx or rubric PDF to place in it, ask where to find them; otherwise leave the folder ready to receive them.
4. Do not move, rename, or overwrite any existing assignment folders.
