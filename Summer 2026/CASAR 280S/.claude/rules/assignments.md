# Assignments Folder Pattern

Each graded assignment lives in its own subfolder under `Assignments/`, e.g. `Assignments/Food Journal Assignment 1/`:

```
Assignments/Food Journal Assignment N/
├── casar280_FoodJournalAssignment.docx   # blank assignment template/instructions
├── Food Journal Assignment N Rubric.pdf  # grading rubric (blank template, not filled-in feedback, unless noted otherwise)
└── Work Done/                            # the user's completed submission (docx + pdf)
```

- **Folder casing is inconsistent** between assignments (e.g. `Work Done` vs `work done`) — match the actual folder name on disk, don't assume capitalization.
- The rubric PDF is normally a blank grading template. Only treat it as facilitator feedback if it's actually been filled in — check before assuming feedback exists (see the facilitator-feedback rule in [[writing-requirements]]).
- When starting a new numbered assignment in the series, read the prior assignment's `Work Done/` submission and its rubric (if filled in) before drafting, per [[writing-requirements]].
